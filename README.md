# hxwl-08 盲品样酒调度看板

盲品课样酒（整瓶 / 开瓶余量）的排课调度与占用判断系统，避免库存与开剩被重复计算。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 调度规则

- 酒款库存：整瓶与开瓶余量分开记账，开瓶（含确认上酒时现场开瓶）必须登记保鲜截止
- 排课：先用未过期余量，再补整瓶（每瓶 12 份）；同一时段超出可出库份数的课程留在待配区并标注缺几份
- 占用判断：同一日期同一时段内，已排课与待配课程锁定的份数先行扣除，避免几个班次算到同一瓶
- 讲师确认上酒后份额才扣减：先按保鲜截止先到期先出扣余量，再开整瓶，新瓶余量登记保鲜截止
- 取消课程：整瓶占用退回库存，开瓶余量保留到保鲜结束；重开的课程重新做占用判断接着排
- 已上酒 / 已取消的课程可存档，看板数据经 localStorage 持久化

## 目录结构（资料 / 占用判断 / 存档 / 页面分离）

- `src/domain/` — 资料与占用判断：`types.ts`（资料结构）、`seed.ts`（初始资料）、`allocation.ts`（占用判断与课程操作）、`dates.ts`
- `src/store/` — 存档与状态机：`archive.ts`（localStorage 读档/存档）、`board.ts`（动作分发）
- `src/pages/`、`src/components/` — 页面：看板、库存面板、排课表单、课程卡片、存档区
